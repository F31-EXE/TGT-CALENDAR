# THE GRIM TEAM — мобильное приложение (React Native / Expo)

Нативное приложение для iOS и Android на Expo (React Native). Использует тот
же бэкенд, что и веб-версия — Firestore (проект `strikeball-calendar`),
данные читаются по REST API.

## Что уже готово

- **Навигация** — нижние табы: Игры, Блог, Барахолка, Ещё. Тёмная военная
  тема как в вебе.
- **Игры** — три режима: список ближайших, **календарь-сетка месяца** (точки
  на днях с играми, тап по дню → игры этого дня) и архив. Экран игры:
  дата/место/теги, **список участников** («Пойдут: N» из RSVP), ссылка на
  Яндекс.Карты и анонс ВК.
- **Пуш-напоминания об играх** — кнопка «Напомнить об игре» ставит локальное
  уведомление за сутки до старта (expo-notifications).
- **Блог** — список статей и чтение с заголовками H2/H3 и списками.
- **Барахолка** — **поиск** и **сортировка** (новые/дешевле/дороже), фильтр
  по категориям и пересылу, бейджи (категория, обмен, торг, пересыл),
  **детальный экран с галереей фото**, «Написать продавцу» / «Предложить
  цену» → чат ВК.
- **Поиск по блогу**, **«Поделиться»** игрой/статьёй (нативный шэринг на
  серверные страницы сайта).
- **Тап по пушу «Новая игра»** открывает эту игру в приложении.
- **Серверные пуши о новых играх** (Cloud Function + Expo Push).
- **eas.json** уже настроен — `eas build` заработает сразу.
- **Ещё** — справочники **Команды / Мастера / Организаторы / Клубы**,
  **Вопросы и правила** (FAQ), **Хронограф** (калькулятор энергии + лимиты),
  ссылки на сайт и администратора.

## Что дальше (следующие этапы)

- Серверные пуши всем — о новых играх и объявлениях (Expo Push + функция-отправитель).

## Как запустить на телефоне за 2 минуты (режим разработки)

1. Установи зависимости:
   ```bash
   cd mobile
   npm install
   ```
2. Запусти сервер разработки:
   ```bash
   npx expo start
   ```
3. На телефоне установи приложение **Expo Go** (App Store / Google Play),
   открой камеру и наведи на QR-код из терминала — приложение откроется вживую.
   Все правки подхватываются мгновенно.

> Примечание: пуш-уведомления в Expo Go работают ограниченно. Полноценно они
> проверяются в собранном приложении (dev build / стор-сборка, см. ниже).

## Как собрать для App Store и Google Play (EAS)

Нужны аккаунты разработчика: Apple Developer ($99/год) и Google Play ($25 разово).

1. Установи EAS CLI и войди:
   ```bash
   npm install -g eas-cli
   eas login
   ```
2. Инициализируй проект (создаст `eas.json` и привяжет к твоему Expo-аккаунту):
   ```bash
   eas build:configure
   ```
3. Собери:
   ```bash
   eas build -p android      # AAB для Google Play
   eas build -p ios          # IPA для App Store (сборка идёт в облаке Expo)
   ```
4. Отправка в сторы:
   ```bash
   eas submit -p android
   eas submit -p ios
   ```

iOS-сборку EAS делает в облаке, поэтому Mac для самой сборки не обязателен —
но Apple-аккаунт и данные для подписи понадобятся.

## Структура

```
App.js                 навигация (табы + стеки), тема
app.json               конфиг Expo: имя, bundle id, иконки, пуши
src/theme.js           цвета/константы
src/firestore.js       клиент Firestore REST (чтение)
src/api.js             загрузка игр/блога/барахолки, форматирование
src/notify.js          разрешения и локальные пуш-напоминания
src/ui.js              общие компоненты (Loading, Empty, Tag, Badge)
src/screens/           экраны
```
